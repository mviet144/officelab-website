03 · How I work

How I work

These tools touch your numbers, so they have to be trustworthy before they're fast. Every Office Lab tool follows the same four rules.

  1. § 1

    Never guess a number

    If a value isn't certain, it stays blank with a reason attached. It's never filled in just to complete the column. An empty cell is far easier to deal with than a wrong number nobody notices.

  2. § 2

    Flag anything uncertain

    Output always keeps the items that need a human check in a separate list, each with a specific reason. You know exactly where to look instead of re-checking everything.

  3. § 3

    Go to the source

    If the original record exists, use it. With e-invoices, the XML file is always trusted over the PDF. The PDF is only used as a cross-check.

  4. § 4

    Automate only what repeats

    A one-off job is usually faster by hand than writing a tool for it. The tasks that come back every week are the ones worth handing to a machine.
